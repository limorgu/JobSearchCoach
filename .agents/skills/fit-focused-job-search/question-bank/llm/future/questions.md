# Future LLM Questions

- Define a task, users, and failure costs for an LLM-assisted workflow.
- Propose a synthetic, privacy-safe evaluation set and explain what it cannot prove.
- Choose quality, safety, and latency/cost metrics with explicit trade-offs.
- Diagnose prompt, retrieval, model, and policy failure modes without assuming a single cause.
- Design a human-review boundary and monitoring plan for a high-impact use case.
