# Resources, resumes, and connections

## Resource ladder

Offer the least intrusive route that can complete the task:

1. Paste a resume or job description.
2. Upload selected files.
3. Connect one curated folder.
4. Connect a historical submissions folder.
5. Connect email, calendar, or professional sources only for a defined benefit.

Before requesting a connector, state:

- what will be read;
- why it is needed;
- what output it enables;
- the manual alternative.

If access fails, do not pretend the resource was read.

## Progress-monitoring sources

If the user wants continuity across days, preferred approved sources are:

- a curated Drive folder for resumes, job descriptions, or tracking files;
- a curated submissions folder;
- a Gmail label, query, or thread used for submission tracking;
- a user-authored self-check-in email thread;
- calendar read access only when needed to place new work blocks with approval.

Use the narrowest source that can answer the question.

## LinkedIn and professional-network sources

If the user wants contact recommendations, acceptable narrow sources include:

- a LinkedIn profile URL the user explicitly provides;
- an exported connections file the user explicitly approves;
- a pasted list of relevant contacts;
- a manual note describing target companies and known connections.

Before using a network source, state:

- what specific source will be read;
- whether it is being used for connection discovery, relationship ranking, or message drafting;
- that reading it does not imply sending outreach.

## Resume library model

Recommend two user-controlled collections:

- **Current role-family bases:** truthful, maintained resumes for major categories.
- **Historical submissions:** older applications used as evidence and wording references.

Mark applications that produced interviews. Prefer the closest current role-family base. Use historical files to learn patterns, not to restore unsupported or outdated claims.

## Gmail and Drive monitoring

When Gmail or Drive is approved, extract only operational signals such as:

- which applications were sent;
- which submissions produced interviews or replies;
- which companies are active;
- which preparation topics already received time;
- whether a user completed or skipped a planned block.

Do not infer facts not supported by the approved source. Reading a thread does not authorize replying, editing, or sending.

## Adaptation limits

For a job report, normally suggest only:

- headline or summary emphasis;
- relevant keywords already supported by experience;
- bullet ordering;
- three to five precise bullet edits;
- projects, publications, or portfolio items to foreground.

Preserve employers, titles, dates, tools, metrics, responsibility, and outcomes. If the source resume cannot be retrieved confidently, provide replacement wording for limited sections instead of generating a supposedly complete resume.

## Connection workflow

1. Identify what help is needed: team insight, recruiter perspective, introduction, referral, or informational conversation.
2. Search only approved sources.
3. Verify full name, current or known role, relationship context, and evidence source.
4. Rank direct team connection, trusted company colleague, relevant recruiter, then credible weak tie.
5. Match the request to relationship strength.
6. Prefer the next best contact for the current goal, not the highest-status contact overall.

Do not recommend an immediate referral request to a new or weak connection by default. Do not invent email addresses or merge people with similar names.

## Daily contact recommendation output

When the user wants daily or weekly networking guidance, return a short ranked list:

1. top one to three people to contact now;
2. why each is timely;
3. what kind of ask is appropriate;
4. whether the coach should draft a message next.

## Output for each suggested person

- verified name;
- company, role, or relationship context;
- why relevant;
- evidence source;
- appropriate route: insight, introduction, conversation, or referral;
- short truthful message under 100 words.

If no verified connection exists, say so and provide exact search criteria plus a placeholder-based cold message.
