# Daily and recurring planning

## Priority order

Use this default order and adapt it to the user's goals:

1. interviews, recruiter requests, referral deadlines, and exceptional matches;
2. targeted applications and relationship actions;
3. portfolio or evidence-building work;
4. lower-priority exploration;
5. optional user-approved routine anchors such as exercise or meditation.

When new evidence from recordings, transcripts, or review notes changes the picture, reprioritize the next day instead of preserving the previous order mechanically.

Do not schedule every category every day.

## Daily task format

Each task must include:

- exact time or duration;
- one action;
- why it matters now;
- definition of done;
- necessary link, file, schema, or chat instruction.

Avoid vague tasks such as “network” or “apply to jobs.”

## Daily routine blocks

When the user wants a repeatable routine, the plan may include:

- a focused application or networking block;
- one adjustment driven by what the latest review or recording revealed;
- optional movement or meditation blocks if the user wants them protected;
- a 5-minute end-of-day completion note or self-reply email;
- a short sentence, reflection, or reminder when the user asked for that style of support.

## Capacity rules

- Respect fixed commitments and stated work windows.
- Keep application volume within the user's chosen limit.
- Use optional movement, meals, breaks, or grounding as supportive anchors only when requested.
- Never make health claims or request diagnoses.
- Prefer a smaller executable plan over an ambitious plan likely to fail.
- Adapt the plan to the user's real concentration window rather than distributing tasks evenly.

## Feedback loop

Accept lightweight status such as:

- completed;
- unfinished;
- applied;
- interview invited;
- rejected;
- no longer interested;
- needs continuation.

Status may come from:

- direct user message;
- approved Gmail thread used as a self-check-in log;
- approved submissions or tracking folder;
- approved recording, transcript, or review note;
- explicit manual notes from the user.

Carry forward only important unfinished work. Do not repeatedly reassign completed applications or contacts without a new reason.


## Recurring report design

Before creating a schedule, show and obtain approval for:

- purpose and output;
- cadence and timezone;
- search window;
- hard filters;
- approved data sources;
- delivery destination;
- whether delivery is a draft or automatic;
- follow-up feedback format.

For an evening opportunity report and morning plan:

1. evening report verifies and ranks only strong matches;
2. evening feedback should capture what was completed or missed;
3. morning plan reads the latest report, review signals, and current commitments;
4. urgent opportunities override routine work;
5. completion feedback informs the next plan.

## Friday science brief

If enabled, every Friday include one short research or science brief selected from approved sources or an approved reading list.

The brief should include:

- title and link;
- why it matters to the user's current search;
- three to five takeaways;
- one suggestion for how to use it in an application or career decision.

Never create scheduled tasks or send recurring messages without explicit authorization.
