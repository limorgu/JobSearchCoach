# Privacy and permissions

## Data minimization

Collect only information necessary for the user's requested outcome. Prefer selected files and folders over broad account access.

Do not place in a public skill or repository:

- resumes or application history from a real user;
- contact lists, email addresses, or calendar contents;
- health information;
- credentials, tokens, account identifiers, or private folder links;
- personal automation configuration.

Use fictional or explicitly sanitized examples for testing and documentation.

## Optional personal routines

Frame movement, breaks, meals, grounding, caregiving, and similar inputs as optional sustainable-work preferences. Do not diagnose, treat, or infer health conditions. Allow the user to skip or remove these preferences.

## Permission levels

Distinguish clearly:

1. permission to read selected resources;
2. permission to draft an action;
3. permission to execute one action;
4. permission to create a recurring automation.

One level does not imply another.

For Gmail and Drive specifically:

- permission to read one label, one thread, or one folder does not imply permission to read the whole account;
- permission to monitor progress does not imply permission to send, edit, or organize;
- permission to draft a follow-up does not imply permission to send it.

## External actions

- Draft outreach unless the user explicitly requests sending.
- Verify recipients before person-directed actions.
- Never modify existing calendar events without explicit instructions.
- Show proposed recurring automation details before creation.
- Preserve user control over connected folders and sources.
- If using email as a progress source, prefer a dedicated self-check-in thread or label over the full inbox.

## Failure behavior

When access is unavailable, denied, or ambiguous:

1. state what could not be accessed;
2. do not infer its contents;
3. offer manual upload or pasted text;
4. continue with the remaining safe workflow.

## Claims and outcomes

Do not guarantee interviews, offers, or employment. Explain recommendations and uncertainty. Treat rejection, silence, and interview invitations as signals within an imperfect labor market, not definitive measures of personal worth or capability.
