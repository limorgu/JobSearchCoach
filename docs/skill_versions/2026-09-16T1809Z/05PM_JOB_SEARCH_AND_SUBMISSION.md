# 05:00 PM Job Search & Submission — Current Version

## Purpose

Use 17:00 as the single organized daily window for job discovery, fit assessment, resume tailoring, cover-letter preparation, LinkedIn contact research, submission tracking, and next-action planning.

The email must be self-sufficient: after reading it, Limor should know exactly what to do without reconstructing context from prior chats.

## Schedule

- Monday–Thursday at **17:00 America/Los_Angeles**.
- Morning remains reserved for technical Data Science practice.

## Goal section — required at the top of every email

Begin with a concise `Goal` section explaining the current objective:

- find recently published Data Scientist roles that are realistically actionable now;
- prepare complete application materials for the strongest matches;
- surface useful LinkedIn contacts;
- make the next actions clear enough to execute directly from the email.

## Current search target

Prioritize Data Scientist roles around **~3 years experience level**, especially:

- Product Analytics;
- experimentation / causal or measurement-heavy roles;
- behavioral or human-centered data science;
- AI evaluation;
- research/data science;
- adjacent analytical roles with strong fit.

Location/employment preferences:

- Remote US is allowed and preferred when strong;
- Seattle / Redmond / Bellevue / Kirkland area roles are preferred locally;
- full-time, contractor, contract, and temp roles are all allowed;
- exclude roles requiring direct people management;
- avoid roles whose central requirements clearly exceed demonstrated experience.

Amazon Data Scientist roles remain held until the technical-readiness gate is met unless explicitly requested otherwise.

## Recency rule

Search deeply for roles **published within the last 5 days** whenever the source provides a posting date.

- Prefer the freshest verified postings.
- If the date is unavailable, mark recency as `unverified` rather than implying the role is recent.
- Do not pad the email with old or weak postings just to produce volume.

## Fit threshold

Surface roles only when the estimated fit is **>=75%**.

The estimate must be grounded in the actual posting and demonstrated experience. Never invent skills or treat unsupported production-ML/foundation-model-training requirements as a match.

## Canonical resume format — required

Every tailored resume must use **`LimorKissosPhDOpenAIChildSafety`** as the exact visual template.

Preserve:

- compact two-page look;
- single-column layout;
- same typography hierarchy;
- same margins and spacing;
- same bullet style;
- same section treatment and density;
- same overall visual hierarchy.

Do not substitute a “normal format,” sidebars, multiple columns, oversized headings, or other stylistic reinterpretations.

Content may be tailored, but the visual format must stay fixed.

### Content that may be tailored

- role headline;
- Summary;
- experience emphasis and bullet ordering;
- Selected AI & Data Projects;
- Core Competencies.

### Content that must remain factually accurate

- Professional Experience claims;
- Selected Publications;
- Education;
- tools, model ownership, and production responsibilities.

Never invent experience, tools, production ownership, or model-training expertise.

## Mandatory package for every >=75% role

For each qualifying role:

1. verify the posting is current;
2. note whether it was published within the last 5 days;
3. create a job-specific resume DOCX using the canonical visual template;
4. create a concise job-specific cover letter DOCX;
5. save the files in the private application working storage;
6. add/update the application tracker row with date, company, role, job link, resume link, cover-letter link, status, source/location, posting recency, LinkedIn contact, and notes;
7. never mark `Submitted` unless submission is actually confirmed;
8. use the connected LinkedIn integration to identify a relevant recruiter, hiring-manager-adjacent person, team member, or Data Science contact when possible;
9. clearly distinguish `relevant contact` from `confirmed recruiter`, `confirmed hiring manager`, or `confirmed 1st-degree connection`;
10. include a concise tailored LinkedIn outreach blurb;
11. visually verify the resume against the canonical template before delivery.

## Required per-role email block

For every surfaced role, include:

```text
[Role] — [Company] | Fit: [NN%] | Posted: [date / within 5 days / recency unverified]
Why it fits: [one concise evidence-based sentence]
Job: [direct employer application link]
Resume: [verified private resume link]
Cover letter: [verified private cover-letter link]
LinkedIn contact: [person + profile + relationship/status qualifier]
Suggested LinkedIn blurb: [2–4 concise sentences]
Next action: [specific action]
```

The `Next action` must be concrete, for example:

- submit tonight;
- message the contact before applying;
- apply first, then send referral note;
- save for referral;
- follow up on an existing submission.

## Suggested LinkedIn blurb standard

Keep outreach concise, natural, and specific to the role/company. The note should:

- identify the exact role;
- state 1–2 relevant strengths grounded in actual experience;
- ask for a small, appropriate action such as insight, routing, or referral consideration;
- avoid overclaiming familiarity or relationship strength.

## Today’s action plan — required

After the role blocks, add a short ordered `Today's action plan` so Limor can execute the session directly.

Example structure:

1. submit Role A;
2. message Contact A using the prepared blurb;
3. review Role B resume and submit;
4. update the tracker status after submission.

## Other fresh opportunities worth trying

If there are additional recent roles above 75% that are worth considering but do not yet justify a full application package, include a short section:

`Other fresh opportunities worth trying`

For each, include:

- role;
- company;
- fit estimate;
- direct job link;
- posting recency;
- one-sentence rationale.

Keep this selective and recent.

## No-match behavior

If no verified >=75% match is found in the fresh search window, send a concise note saying so and include the application-log reference. Do not fill the email with weak matches.

## Application log

The application tracker is part of the routine and should be updated before the email is sent.

Track:

- date;
- company;
- role;
- direct job link;
- resume link;
- cover-letter link;
- status;
- source/location;
- posting recency;
- LinkedIn contact;
- notes.

This tracker is the continuity layer across sessions and must be consulted for deduplication before a new search.

## Session flow

The intended 17:00 operating sequence is:

`deep fresh search -> assess fit -> generate tailored materials -> identify LinkedIn contact -> write outreach blurb -> update tracker -> send complete package -> execute next actions`

## Recovery rule

If this routine must be rebuilt, restore the separation:

**07:00 = technical practice. 17:00 = job search, resume/application packaging, LinkedIn outreach, and submission tracking.**
