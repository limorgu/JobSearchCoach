# Job Search Coach Daily Routine

This coach is a job-search operating routine. It does not require a coding or database environment.

## 7am: create the plan

Ask the coach for a short, realistic plan based on current priorities, constraints, and evidence. The plan should include the most important action, high-fit opportunities, applications or follow-ups, networking suggestions, and a definition of done for each action.

## 5pm: close the loop

Report what was completed, what remains, important outcomes, new constraints, and useful new opportunities. The next 7am plan adapts from this evidence.

## 9pm: private progress record

The dedicated progress agent records the day's real applications, networking outcomes, completed work, constraints, dashboard results, and next-day context in local `private-progress/`. This folder is gitignored and never part of the public coach interface.

## Separate technical practice

SQL, Python, ML, and other technical-interview practice live in the separate [DataScienceSprintCoach](https://github.com/limorgu/DataScienceSprintCoach) repository. That coach has its own VS Code and SQLite environment, question bank, datasets, and private progress record.
